# ADR-004: Ember Cache를 Redis 대신 로컬 SSD 기반으로

- 상태: 채택 · 날짜: 2026-07-14

## 맥락
엠버 캐시(Ember Cache)는 처음에 Redis 클러스터였다. 공장 네트워크가 끊기면 카파 격자가 특징량을 못 읽어
레드라인 지수 계산이 멈췄다.

## 결정
- `ember_cache`를 에지 서버의 로컬 SSD로 옮긴다(RocksDB).
- Tide Gate와 같은 장비에서 돈다. 네트워크 단절 시에도 72시간 동작.
- Twin Window Correction 단계도 같은 장비로 옮길지는 보류.

## 결과
- 블루 시프트 이후 복구 시간이 20분 → 3분.
- 오리노아 모터스 쪽 네트워크 장애와 무관하게 퀼미어 점수가 계속 나온다.
