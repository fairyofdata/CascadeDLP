# P4 1차 — 규칙만 vs 규칙+LLM vs GLiNER (eval_v1)

Ollama 0.34.4, RTX 3070 8GB, LLM 3종 모두 100% GPU·num_ctx 8192. GLiNER는 CPU.
평가 세트는 분석자 생성 합성 56문장/75스팬.
⚠ 평가 세트·규칙·프롬프트·후처리를 모두 같은 쪽(분석자)이 만들었고, **v2 후처리와 연결 판정 코드는 이 세트의 오류를 보고 고쳤다** → 과적합 포함. 절대값보다 상대 비교로 볼 것. 새 합성 세트(v2)로 재확인 필요.

## 버전
- **v1**: 탐지 프롬프트 + 연결(표기 44개를 한 번에 묶게 함)
- **v2**: 같은 탐지 프롬프트 + 결정론 후처리(같은 유형 조각 병합, 호칭 제거) / 연결은 LLM이 표기마다 로마자 발음만 → `linking.py`가 판정
- v2 연결 점수는 판정 코드 수정 후 **저장된 LLM 출력으로 재채점**(`tools/relink.py`, LLM 재호출 없음). 수정 전 값은 결과 JSON의 `linking_before`.
