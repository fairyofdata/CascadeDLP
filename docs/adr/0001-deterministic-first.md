# ADR-0001 결정론이 먼저, 로컬 LLM은 형식 없는 것만

- 날짜: 2026-09-29 · 상태: 채택

## 맥락
외부 LLM에 보내기 전 개인정보를 가리는 레이어는 **틀리면 유출**이고, 같은 입력에 같은 결과가 나와야 장기 KB에서 토큰이 안정적이다. LLM은 형식 없는 것(이름·주소 조각)을 잘 찾지만 비결정적이고 환각이 있다.

## 결정
| 규칙(정규식) | 로컬 LLM | LLM에게 맡기지 않음 |
|---|---|---|
| 메일·전화(한/일/국제)·우편번호·URL·주민번호·마이넘버·여권(키워드 문맥) | 이름·주소·조직명 **후보 문자열**, 이름의 **로마자 발음** | 스팬 위치, 토큰 부여, 매핑 저장, 복원, 같은 사람 판정, 점수 집계 |

- LLM은 문자열만 낸다. **위치(start/end)는 코드가 원문에서 찾는다** → 원문에 없는 문자열(환각)은 자동 폐기.
- 겹치면 규칙이 이긴다(`spans.resolve`: 규칙 > LLM, 그다음 긴 쪽).
- LLM 호출은 `temperature 0`, `think: false`, JSON 스키마 `format`.

## 결과
- 규칙 유형은 LLM을 더해도 정확도가 떨어지지 않는다(eval_v1·v2 모두 1.0 유지).
- LLM 기여를 따로 잰다: 규칙만 F1 0.404 → 규칙+LLM 0.873 (qwen3.5:9b, eval_v1). Δrecall +0.57~0.63.
- 단점: 규칙은 만든 사람이 본 형식에만 맞는다 → [ADR-0010](0010-holdout-and-overfitting.md)에서 과적합 확인.
