# ADR-0003 평가 지표

- 날짜: 2026-09-29 · 상태: 채택 (사용자 선택: "완전 + 겹침 두 가지")

## 결정
- **탐지**: 유형별 precision / recall / F1을 두 기준으로.
  - 완전 일치: start·end·유형 모두 같음.
  - 겹침 일치: 유형 같고 한 글자라도 겹침(예측 하나는 정답 하나에만 대응).
- **교차 표기 연결**: 정답 PERSON 표기 전체를 입력(탐지와 분리)
  - 묶음 완전 일치: 정답 묶음의 모든 표기가 한 묶음에 있고 다른 사람이 섞이지 않은 비율.
  - 쌍 단위 P/R/F1. **쌍 P가 가장 중요** — 두 사람이 한 토큰이 되면 복원 시 사람이 바뀐다.
- **지연**: 문장당 ms(첫 문장 제외 — 모델 로딩).
- **P5**: 토큰 보존율, 지어낸 토큰, 변형 토큰 ([ADR-0014](0014-p5-local-transform.md)).
- 결과는 `results/<날짜>_<평가세트>_<모드>[_모델]_<파이프라인버전>.json/.md`. 원문 없이 수치 + 오류 목록(합성 데이터라 표기 포함).

## 결과
- 겹침 점수만 보면 잘못된 판단을 한다: GLiNER는 겹침 F1 0.94지만 일본어 문장을 통째로 잡는다([ADR-0009](0009-gliner-baseline.md)). **완전 일치를 주 지표로** 본다.
