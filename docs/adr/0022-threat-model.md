# ADR-0022 위협 모델: 이 도구가 약속하는 것과 약속하지 않는 것

- 날짜: 2026-10-03 · 상태: 채택

## 배경 (프로젝트의 출발점)
수탁개발처럼 남의 코드를 다루는 일에서는 **"고객사 소스코드 외부 반출 금지"** 가 흔한 기본 방침이다. 이 프로젝트는 그런 제약을 마스킹으로 넘어 볼 수 있는가 하는 아이디어에서 착안했고, 개인정보 가림부터 만들었다.
만들면서 알게 된 것: **소스코드의 핵심 로직은 가릴 기준 자체가 없다.** 무엇이 핵심인지는 도메인 지식과 프로젝트 이해에 달려 있고 주관적·맥락적이다. 그리고 이름을 가려도 의미는 새어 나간다([ADR-0019](0019-semantic-leakage.md)).

## 결론부터
**이 도구는 "외부 반출 금지" 방침을 충족시키지 않는다.** 가린 문서·코드를 클라우드에 보내는 것도 반출이다.
이 도구는 **보장 장치가 아니라 위험 감소 계층**이다 — 반출이 허용된 자료를 다룰 때 실수로 나가는 식별 정보를 줄이고, 나가면 안 되는 문서를 로컬에 붙잡아 둔다.

## 지키려는 것(자산)과 실제 보호 수준
| 자산 | 이 도구가 하는 일 | 측정된 수준 (합성 데이터) | 남는 위험 |
|---|---|---|---|
| 개인정보 (이름·연락처) | 탐지해 토큰으로 가림 | 탐지 F1 0.87, 문서 단위에서 가끔 놓침 | 약 8건 중 1건이 나갈 수 있음. 직함·날짜 등 주변 맥락으로 누구인지 추론 가능(가명화이지 익명화가 아님) |
| 식별자 (고객사명·프로젝트명·컴포넌트명) | 용어집에 있으면 가림, 없으면 보류 후 사용자 확인 | 용어집에 있으면 노출 0. 없으면 87–93% 보류 | 용어집에 없는 한국어·일본어 용어의 7–13%는 통과 |
| 비밀키 | 형식 규칙으로 차단 | 접두 형식이 있는 키만 | 형식이 없는 비밀번호·토큰은 못 잡음 |
| **의미** (설계 의도·알고리즘이 무엇을 어떻게 하는가) | **가림으로는 보호 못 함.** L3로 지정하면 문서째 로컬 전용 | 가려도 의미 유출 0.89–0.94 (원문 수준) | L3로 지정하지 않은 문서의 의미는 그대로 나간다. 무엇을 L3로 둘지는 사람의 판단 |
| **소스코드 자체** | **범위 밖** (문서만 지원) | — | 반출 금지 방침 아래에서는 이 도구로 해결되지 않는다 |

## 상대(누구로부터)
1. **사용자 자신의 실수** — 민감한 문서를 무심코 클라우드 대화에 넣는 것. 이 도구가 가장 잘 막는 대상(관문·보류·감사 로그).
2. **클라우드 쪽에 남는 기록**(로그·보관·열람) — 식별자가 가려진 만큼만 줄어든다. 의미는 남는다.
3. **가린 텍스트에서 원래 대상을 추론하려는 모델·사람** — 이름은 못 맞혔지만(이름 복원 0), 의미는 거의 다 복원했다. 실제 최상위 모델은 측정에 쓴 로컬 모델보다 더 잘 추론할 것이다.

## 전제(깨지면 보호도 깨진다)
- 로컬 PC와 `~/.cascadedlp/`(가명 맵·용어집·대기 목록, **암호화하지 않은 평문**)는 안전하다.
- 호출하는 쪽(Claude Code 등)이 **관문을 거친다.** 지금은 강제 장치가 없어 파일을 직접 읽으면 우회된다(후속 과제, [ADR-0021](0021-cascade-confirmation.md)).
- 용어집과 L3 지정이 실제 프로젝트의 민감한 대상을 반영한다(사람의 몫).

## 쓸 수 있는 상황 / 쓸 수 없는 상황
| 쓸 수 있다 | 쓸 수 없다 |
|---|---|
| 반출이 허용된 자료(공개·내부 일반 문서, 개인 프로젝트)에서 식별 정보 노출을 줄이고 싶을 때 | "외부 반출 금지"인 고객사 소스코드·설계서를 클라우드 모델로 다루려 할 때 |
| 무엇을 로컬에 붙잡아 둘지 등급(L0–L3)으로 관리하고, 나간 것을 기록하고 싶을 때 | 규정 준수의 근거로 삼으려 할 때(보장이 아니다) |
| 로컬 모델만으로 처리해도 되는 민감 문서(L3) | 의미가 비밀인데 클라우드 성능이 꼭 필요한 작업 — 이 경우의 답은 가림이 아니라 **사내·로컬 모델**이다 |

## 이 프로젝트가 보여 준 것
1. **마스킹으로는 "반출 금지"를 넘을 수 없다** — 추측이 아니라 측정으로: 이름을 다 가려도 의미 유출 0.89–0.94, 문장을 지워도 0.4가 남고 그때는 효용이 0이 된다.
2. 그러면 가능한 것은: (a) 반출이 허용된 자료에 대한 **실수 방지 계층**, (b) 문서를 민감도로 분류해 **보낼지 말지를 정하는 틀**(관문 판정·용어집·감사 로그), (c) 의미가 비밀인 자료는 **로컬·사내 모델**로 — 그 경로가 이미 판정에 들어 있다(L3).
3. 8GB GPU 한 장으로도 관문 역할(탐지·용어집 초안·판정)은 돌아간다. 본 작업을 대신할 성능은 아니다.
