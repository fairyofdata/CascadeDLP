# ADR-0005 가명 맵 형식: 엔티티 중심 JSON + 작업별 복원표

- 날짜: 2026-09-29 · 상태: 채택 (사용자 선택)

## 결정
```json
{"version": 1, "counters": {"PERSON": 2},
 "entities": {"[PERSON_001]": {"type": "PERSON", "surfaces": ["한서윤", "ハン・ソユン", "Seoyun Han"]}},
 "romanized": {"한서윤": {"family": "han", "given": "seoyun", "nationality": "korean"}}}
```
- 토큰 하나에 여러 표기 → 교차 표기 연결과 "다음 주에도 같은 토큰"을 자연스럽게 지원.
- 표기 조회는 정규화(NFKC·대소문자·공백·가운뎃점 무시).
- **복원표**(`restore/<job_id>.json`): mask 한 번마다 토큰이 나온 순서대로 원래 표기. 같은 토큰이 문서 안에서 다른 표기였어도 **원문과 바이트 일치** 복원.
- 외부 LLM 답에서 토큰이 늘거나 순서가 바뀌면: 그 문서의 첫 표기 → 맵의 첫 표기 → 토큰 그대로.
- 원문에 이미 `[TYPE_001]` 모양이 있으면 거부(복원 모호).
- `romanized`: 로마자 캐시(2026-09-30 추가) — 새 표기만 LLM 호출.
- 파일은 임시 파일에 쓰고 `os.replace`(중간에 끊겨도 반쯤 쓰이지 않게).

## 결과
- 라운드트립 테스트: 평가 문장 전체 + CRLF 파일 + md/json 파일 바이트 일치.
- 한계: 같은 표기의 동명이인은 구분 못 한다(표기가 같으면 같은 토큰).
