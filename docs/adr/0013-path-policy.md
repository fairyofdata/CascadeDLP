# ADR-0013 MCP 경로 정책: 넓은 울타리 + 항상 차단 + 호출마다 승인

- 날짜: 2026-09-30 · 상태: 채택. 첫 안("허용 폴더 목록만, 기본 비어 있음")을 사용자 의견으로 변경

## 맥락
첫 안은 미리 정한 허용 폴더만 읽게 했다. 사용자 의견: 폴더·파일명·형식(json/md)은 **그때그때 상황에 맞게 지정**하는 게 낫다. 미리 확실히 고정할 필요가 있나?

## 결정
고정 목록 대신:
1. **넓은 울타리**: 기본 `allowed_roots` = 사용자 폴더 전체. 경로는 대화에서 그때그때 지정.
2. **항상 차단**(설정과 무관): 가명 맵 폴더(`~/.piigate`), `.ssh`, `.aws`, `.gnupg`, `.claude`(대화 기록), `AppData`, `.config`, `.docker`, `.kube` — `gate.DENIED_UNDER_HOME`.
3. **호출마다 승인**: Claude Code가 MCP 도구 호출마다 승인 창에 경로를 보여 준다 → 어떤 파일이 나가는지 매번 확인.
4. 쓰기는 울타리 안 **새 파일만**(덮어쓰기 금지). `..` 경로는 `resolve()` 후 검사.
5. UTF-8 텍스트면 형식 무관(.md .json .txt .csv). 복원 파일 이름을 안 정했으면 `<원본>.restored.<확장자>`를 제안(MCP instructions).

## 결과
- 더 좁히고 싶으면 `~/.piigate/config.json`의 `allowed_roots`만 바꾸면 된다.
- 테스트: 울타리 밖 거부, `..` 탈출 거부, 울타리 안이어도 맵 폴더·`.ssh`·`.claude` 거부, 덮어쓰기 거부.
