# ADR-0002 평가 세트: 합성 데이터만, 인라인 마크업으로 작성

- 날짜: 2026-09-29 (v1), 2026-09-30 (v2) · 상태: 채택

## 맥락
이 개발 세션 자체가 외부 LLM이다. 실제 개인정보를 넣을 수 없다. 스팬 오프셋을 손으로 세면 한·일 문자에서 틀리기 쉽다.

## 결정
- **합성 데이터만.** 이름은 지어낸 것, 메일·URL은 예약 도메인(`example.*`), 전화·주민번호는 가상 번호.
- 원본은 `[[TYPE:ENTITY_ID|원문]]` 인라인 마크업 TSV(`data/eval/*.src.tsv`) → `tools/build_eval.py`가 JSONL(start/end) 생성 + 자기 검사.
- `entity_id`가 같으면 같은 사람 → 교차 표기 연결 평가.
- 작성자·건수는 `data/eval/README.md`에 버전별 기록.
- v1(56문장/75스팬, 묶음 9) = 개발용, v2(58문장/77스팬, 묶음 10) = 홀드아웃([ADR-0010](0010-holdout-and-overfitting.md)).
- 한·일·영 혼용을 기본 전제로: 한 문장 속 3언어, 한국어 문장 속 일본어 인용, 한자/가나/한글/로마자 표기, 함정 문장(주문번호·날짜·이름으로도 쓰이는 일반어).

## 결과
- 사용자 작성 세트(eval_v3)는 하지 않기로 함(2026-09-30 사용자 판단: 개인이 쓰면 오히려 편향되고 다양성이 부족). 분석자 생성 세트의 한계는 결과표마다 명시.
