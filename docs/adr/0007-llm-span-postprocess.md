# ADR-0007 LLM 스팬 후처리: 조각 병합·호칭 제거 (결정론)

- 날짜: 2026-09-30 (v2), 명단 예외 v3 · 상태: 채택

## 맥락
eval_v1에서 LLM이 이름을 성·이름으로 쪼갬(`Seoyun`+`Han`, `ハン`+`ソユン`), 주소를 여러 조각으로 냄, 호칭을 포함함(`春ちゃん`, `하늘이`). 특히 4b에서 심해 완전 일치 F1 0.62.

## 결정 (`llm.tidy`)
1. 같은 유형 스팬이 공백·가운뎃점(`・`)·(주소는 쉼표)로만 떨어져 있으면 합친다.
2. **단 이름이 3조각 이상 공백으로 이어지면 명단**(`정민호 김민준 오세린`)으로 보고 합치지 않는다(v3, eval_v2에서 발견).
3. PERSON 끝의 호칭(`ちゃん さん くん 様 씨 님`)과 한국어 `이`+조사(`하늘이가`)를 뗀다.
- 프롬프트가 아니라 코드로 → 모델을 바꿔도 같은 규칙.

## 결과
- 4b F1 0.619 → 0.868, 9b PERSON F1 0.864 → 0.907 (eval_v1).
- 한계: **공백으로만 붙은 2인 명단**(`정민호 김민준`)은 한 사람으로 합쳐진다. 가려지긴 하지만 한 토큰이 되어 교차 연결이 틀어진다.
