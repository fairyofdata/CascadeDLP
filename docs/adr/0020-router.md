# ADR-0020 C5 라우터: 문서 단위로 클라우드 원문 / 가림 / 로컬 전용 / 차단

- 날짜: 2026-10-01 · 상태: 채택 (문서 단위, 로컬 결과는 파일로만, 감사 로그: 사용자 선택)

## 맥락
[ADR-0019](0019-semantic-leakage.md): 가림은 이름을 지키지만 의미는 못 지킨다. 의미가 비밀인 것은 **가리지 말고 로컬에서만** 처리해야 한다. 이를 요청마다 자동으로 판단하는 계층이 필요하다.

## 결정 (`cascadedlp/router.py`)
| 경로 | 조건 | 호출자(Claude)가 받는 것 |
|---|---|---|
| `cloud_raw` | 민감 항목 없음 | 원문 |
| `cloud_masked` | 개인정보·L1·L2 용어만 | 가린 텍스트 + job_id (복원은 로컬) |
| `local_only` | L3 용어 포함 | **내용 없음.** 요청이 있으면 로컬 모델이 답을 **로컬 파일**에 쓰고 경로만 |
| `block` | 비밀키 형식 (`secret_policy=block`, 기본) | 아무것도 없음. `secret_policy=mask`면 가려서 `cloud_masked` |

- **라우팅 단위는 문서 전체**: 의미는 문서 흐름으로 새므로(ADR-0019) 섹션 단위는 쓰지 않는다.
- **감사 로그** `~/.cascadedlp/audit.jsonl`: 시각·경로·원천 해시(파일은 경로 해시)·글자 수·유형별 개수·job_id. **내용·파일명·용어는 남기지 않는다**(테스트로 확인). CLI `mask`·MCP `mask_file`도 기록.
- 진입점: MCP `route_file(path, question?, project?, local_answer_path?)`(권장 진입점으로 instructions에 명시), CLI `cascadedlp route <파일> [-q 요청] [-o 출력]`, `cascadedlp audit`.
- 로컬 답: 문서 앞 12,000자까지, temperature 0.2. 기존 파일 덮어쓰기 금지.

## 결과
- 테스트 134개(네 경로, 비밀키 정책 전환, 로컬 답은 파일로만, 감사 로그에 용어·메일·키·파일명 없음, 울타리 밖 거부).
- 합성 Tessellane 문서 5개를 실제 로컬 LLM으로 라우팅: Braid Solver(L3)가 나오는 **4개는 local_only**, ADR 1개는 cloud_masked.
- ⚠ **실사용 교환**: L3 용어 하나가 문서 대부분에 나오면 거의 모든 문서가 로컬 전용이 되어 클라우드를 못 쓴다. **L3는 의미가 정말 비밀인 소수 항목에만** 지정하고, 나머지는 L2(식별자 보호)로 둔다. 용어집 검토(C2) 때 이 기준을 안내한다.
- 한계: 로컬 모델(qwen3.5:9b, 8K 컨텍스트)의 답 품질은 클라우드보다 낮다. 긴 문서는 앞부분만 쓴다.
