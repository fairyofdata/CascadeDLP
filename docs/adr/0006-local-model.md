# ADR-0006 로컬 모델: qwen3.5:9b를 기본으로

- 날짜: 2026-09-29 후보 선정, 2026-09-30 고정 · 상태: 채택

## 맥락
RTX 3070 8GB. PLAN의 후보(`qwen3:8b`, `gemma3:4b`)는 2026-06 지식 기준. 착수 시 Ollama 라이브러리를 확인하니 `qwen3.5`(0.8b~122b)가 나와 있었다. `gemma4`는 비전·오디오 포함으로 e4b도 6GB+.

## 결정 과정
1. 후보 3개를 받아 실측(사용자 선택): `qwen3:8b`(5.2GB), `qwen3.5:9b`(6.6GB, VRAM 넘침 우려), `qwen3.5:4b`(3.4GB, 같은 계열로 크기 효과만 비교).
2. 스모크 테스트: 세 모델 모두 **100% GPU**, num_ctx 8192 (qwen3.5:9b 적재 5.6GB).
3. eval_v1(개발 세트)에서는 셋 다 비슷(v2 파이프라인 F1 0.87 안팎).
4. **eval_v2(홀드아웃)** 에서 갈림:

| 모델 | v1 F1 | v2 F1 | v1 연결 | v2 연결 | v2 쌍 P |
|---|---|---|---|---|---|
| qwen3:8b | 0.874 | 0.821 | 7/9 | 3/10 | 0.811 |
| **qwen3.5:9b** | 0.873 | **0.875** | 7/9 | **7/10** | **1.000** |
| qwen3.5:4b | 0.868 | 0.787 | 6/9 | 3/10 | 0.903 |

## 결정
기본 `qwen3.5:9b` (`~/.piigate/config.json`의 `model`로 바꿀 수 있음). `--rules-only`로 LLM 없이도 동작.

## 결과
- 문장당 약 2.8초. 소형(4b)도 2.6초로 **빠르지 않다** → 작은 모델을 쓸 이유가 없음.
- 다른 모델로 바꾸면 결과표에 모델 태그를 같이 적고, 버전이 다른 결과를 한 표에 섞지 않는다(CLAUDE.md).
- 운영 메모: `ollama pull`을 **동시에 두 개** 돌렸더니 "part stalled" 재시도가 50분간 반복됨 → 하나씩 받아 해결. `setup.ps1`은 순차 실행.
