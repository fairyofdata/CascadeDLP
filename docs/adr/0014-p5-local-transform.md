# ADR-0014 P5: 가명화 후 로컬 번역·요약 — 토큰 보존 확인

- 날짜: 2026-09-30 · 상태: 측정 완료, 기능은 `piigate/transform.py`에 둠(Gate·MCP에는 아직 미노출)

## 맥락
외부 LLM에 보낼 양 자체를 줄이려면 가명화된 텍스트를 로컬에서 번역·요약할 수 있다. 위험은 토큰이 망가지는 것(`[PERSON_1]`, `【PERSON_001】`, 사라짐, 새로 지어냄 → 복원 실패나 다른 사람으로 복원).

## 결정
- `transform.translate/summarize` (qwen3.5:9b, `temperature 0.2`, `P5_PROMPT_VERSION = p5-v1`): 프롬프트에 "토큰을 정확히 복사, 새 토큰 금지, 호칭은 토큰 밖" 규칙.
- `repair_tokens`: 망가진 모양을 **입력에 있던 토큰으로만** 되돌린다(결정론, 새 토큰을 만들지 않음).
- 측정(`tools/p5_eval.py`): 입력은 정답 스팬으로 가명화(탐지 오류와 분리). eval_v1+v2의 토큰 있는 문장 105개 × 원문 외 2개 언어 번역 = 210건, 10문장 문서 11개 × ko/ja/en 요약 = 33건.

## 결과 (`results/2026-09-30_p5_qwen3.5-9b_p5-v1.json`)
| | 출력 수 | 토큰 보존율 | 완전무결 | 지어낸 토큰 | 변형 토큰 | 중앙 지연 |
|---|---|---|---|---|---|---|
| 번역 | 210 | **1.000** | 210/210 | 0 | 0 | 2.6s |
| 요약 | 33 | 0.872 | 21/33 | 0 | 0 | 4.7s |
- 요약에서 빠진 토큰(PERSON 17, ADDRESS 13 …)은 **내용 생략**이지 손상이 아니다(변형·지어냄 0). 요약이 사람을 빠뜨리는 건 요약의 성질.
- 보정(`repair_tokens`)은 이번엔 고칠 게 없었다(보정 전후 동일) — 안전망으로 유지.
- 품질 메모: 영어 요약에 원문 호칭이 남음(`[PERSON_001] 님`, `[PERSON_001]さん`). 개인정보와 무관, 다음 프롬프트 버전에서 개선 후보.

## 다음
- Gate에 `translate`/`summarize` 옵션을 붙여 MCP에서 "가명화 + 로컬 요약본만 보내기"를 제공할지 결정(보낼 양 감소 vs 로컬 지연 2.6~4.7s).
